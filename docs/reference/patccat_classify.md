# Classify patent claims (alias for fn.patccat)

Idiomatic alias for
[`fn.patccat`](https://bganglmair.github.io/patccatClaims/reference/fn.patccat.md);
identical arguments and return value.

## Usage

``` r
patccat_classify(data, ...)
```

## Arguments

- data:

  A data frame of claim lines (see
  [`fn.patccat`](https://bganglmair.github.io/patccatClaims/reference/fn.patccat.md)).

- ...:

  Passed to
  [`fn.patccat`](https://bganglmair.github.io/patccatClaims/reference/fn.patccat.md).

## Value

See
[`fn.patccat`](https://bganglmair.github.io/patccatClaims/reference/fn.patccat.md).
